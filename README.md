# Bücherregal

An Android app that works as a virtual bookshelf.

You can save the books you have read and sort other books into more shelves, for example "To Be Read" and "Want to buy". The app is mainly built for private use by me and my wife.

## Roadmap

The planned steps and their order are in [`ToDo.txt`](ToDo.txt).

## Tech Stack

- Kotlin
- Jetpack Compose
- Google Sign-In
- Google Drive API (private app data folder)
- Minimum SDK: API 26
